# Samsarix brand guide

The current company and product identity is:

- Company: **Samsarix LLC**
- Product: **Samsarix Agent Readiness Registry**
- General and licensing email: `contact@samsarix.com`
- Product, support, and security email: `support@samsarix.com`

Use “Samsarix” for maintained user-facing copy, metadata, release artifacts, and new
documentation. Do not invent a Samsarix website, social account, phone number, or
address until the owner confirms it.

The word “Helix” remains in the historical GitHub repository URL, legacy filenames,
archived prototypes, old service identifiers, package namespaces, and preserved
records. Those references describe provenance or compatibility; they are not the
current company identity. New code should not introduce another Helix-branded public
surface without an explicit migration reason.

See `TRADEMARKS.md` for permitted use of Samsarix branding.
